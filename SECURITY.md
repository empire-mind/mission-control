# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Instead, please report them by **opening a private security advisory on GitHub**
for this repository (Security tab → "Report a vulnerability").

We take all reports seriously and will respond as quickly as we can. Please give
us a reasonable amount of time to address the issue before any public disclosure,
and we will keep you informed of our progress.

## Scope

This policy applies to the code and configuration in this repository. If you are
unsure whether something is a genuine security concern, please report it anyway —
we would rather hear about it than miss it.
